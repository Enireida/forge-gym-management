Smart Gym Management System

Project Master Guide

Bachelor Thesis — UNyT Albania

Full-Stack Web + React Native Mobile + Apple Watch / HealthKit + AI

1. Project Overview

The Smart Gym Management System is a complete digital platform for modern fitness centers. It replaces manual paper-based processes used by most Albanian gyms with a unified digital platform across three surfaces:

Web application — admin and trainer dashboard (React.js + Supabase)

Mobile application — member app for iOS (React Native + Expo)

Apple Watch — health data display via HealthKit (steps + heart rate, read-only)

The system handles three user roles: Administrator, Trainer, and Member. Each role has a dedicated interface with tailored permissions and features.

The only Mac dependency is configuring HealthKit permissions in Xcode, which is a one-time setup.
